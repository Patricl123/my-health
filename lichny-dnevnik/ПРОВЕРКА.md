# Проверка дневника «Тихо»

Дата: 9 ноября 2026 года, Europe/Moscow.

Финальная сборка `npm.cmd run build` завершилась успешно. TypeScript проверен, приложение собрано для Firebase Hosting, создан офлайн-кэш оболочки. Облачная конфигурация остаётся незаполненной до настройки вашего Firebase-проекта.

`npm.cmd test`: **7 тестов прошли**, 21,8 секунды. Использованы Chrome, мобильный экран 390 × 844 с сенсорным вводом, второй независимый браузер 375 × 812, настольный экран 1440 × 1024 и настоящие локальные Firebase Authentication / Firestore Emulator. Для этого использован отдельный demo-проект, а не облачная база пользователя.

1. Вход → создание записи только свободным текстом → подтверждённое сервером сохранение → перезагрузка → редактирование настроения, стресса, заметки и питания → чтение и изменение из другого браузера. Горизонтальной прокрутки на мобильном экране нет, ошибок JavaScript нет.
2. История с выбором даты, сохранение стресса **0**, пустые дни на графике, скачивание JSON и проверка его содержимого, отмена удаления и подтверждённое удаление.
3. Обрыв запросов к базе, сохранение черновика, перезагрузка, повторная отправка; полное отключение сети, перезагрузка офлайн-оболочки и повторное сохранение после восстановления связи.
4. Пока ответ сервера задержан, отображается отправка, а не «Сохранено».
5. Конфликт двух устройств оставляет локальный черновик и не перезаписывает свежую серверную запись.
6. Если запись дошла до базы, но ответ потерялся, повтор распознаёт выполненную операцию и не создаёт вторую версию.
7. Firestore запрещает анонимное чтение, чтение, запись и удаление другим аккаунтом, а также некорректные данные владельца.
